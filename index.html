Sobre esta versão

Ela usa a Web Speech API disponibilizada pelo Safari/iOS. Não baixa modelos de IA e não envia o texto para uma API do aplicativo. A disponibilidade e a qualidade das vozes dependem das vozes que o próprio iPhone expõe ao Safari. O progresso e as marcações ficam salvos neste navegador.
